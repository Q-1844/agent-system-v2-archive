## 十、云端自足原则（用户定版：云端系统完美运行不需要执行侧 Claude 参与）

> 场景：用户在**任何人的电脑**上打开云端系统做成片——无法与执行侧 Claude 交互。故云端流程必须全自动化+全文档化。

1. **速度定版（A-B 对接姿势）**：**会话级同步**——会话开始一次性从 B1 拉项目数据链到运行器本地磁盘 → 对话全程本地磁盘读写（**与项目只存 A 速度完全一致，零网络参与**）→ 会话结束成果推回 B1。B 只在会话首尾出现；错误姿势（步级读 B）永不采用。A 保持轻量反使 CI 克隆更快。
2. **归档自动化（并入 producer 新能力 backlog）**：archive 逻辑必须做成系统 agent 可执行脚本（A/tools），战役收尾由 producer/agent 自主调用——云端无执行侧手动环节。
3. **规则全文档化**：流转纪律/触发条件全部写入 STATE.md 与各仓 README——任何机器任何 agent 照做即可。
4. **Secrets 清单（真实云端生成启用时配）**：Agnes API key、推送令牌 → GitHub Actions secrets。
5. 本地=用户测试场（执行侧 Claude 可参与管理）；云端=完整自足系统（无人值守）。此为两条生产线的根本区别。
