## 五、GitHub Actions CI（用户要求 3）

- A 仓 `.github/workflows/ci.yml`：push/PR 触发 → Python 3.11 → 固化依赖（从本机 `pip freeze` 提炼 requirements）→ `pytest -q`（mock 全量，离线零配额）
- 平台：先 `ubuntu-latest`；Windows 特有路径用例若翻车 → 加 `windows-latest` 矩阵或用例归一（路径改 pathlib）
- 已知失败基线（约 291 项）：CI 初期=「回归对照报告」（失败数 ≤ 基线即绿），GPT 修复轮后逐步收紧为硬门禁
- ffmpeg：GitHub runner 预装；rembg 等重依赖若安装过慢 → 评估拆可选依赖层
- 费用：公开仓 Actions 免费额度充足
- 注意：CI 运行不消耗 Agnes 配额（mock）；不配置任何 secrets（测试无需）
