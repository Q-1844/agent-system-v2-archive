# GitHub 四仓迁移报告包（2026-10-20）

## 本报告包是干什么的

本系统正在把本地两套 Git 仓迁移到 GitHub 四仓公开架构。本报告包写给一位**无历史上下文的新窗口 agent**：请基于 01-04 四份报告整理出一份可执行的**《GitHub 推送与迁移实施方案》**。方案产出后交回原执行侧（Claude Code 主会话）核对、结合其上下文修正后执行。**本报告包只做方案输入，新 agent 不执行推送。**

## 阅读顺序

1. `01_系统介绍.md` — 系统是什么、怎么跑、当前状态
2. `02_仓库现状盘点.md` — 本地两仓/远端四仓的全部实测数据
3. `03_迁移要求与红线.md` — 用户三大要求原文+解释、不可违反的红线
4. `04_分类与推送草案.md` — 执行侧初步草案，供修订为实施方案

## 用户三大要求（方案必须逐条覆盖）

1. **提交分好类别**（详见 03 §一）
2. **本地大清理**：只留必要源码+测试必需，其余提交过一律删除（详见 03 §二）
3. **推送后用 GitHub 公开仓自带的系统（GitHub Actions）跑动画工作流测试**，不是本地测试（详见 03 §三、04 §五）

## 已定不可改的决策（新方案必须遵守）

- 四仓架构、全 Public、三个新仓各开 GitHub Pages（清单见 02）
- **推真实 Git 历史**：禁重写历史、禁用源码快照伪装历史（外部协作方 GPT 的 03 文档纪律，da123e2/fecfd5f 两基线哈希被其修复链引用）
- 活 SQLite（运行中数据库）永不进 Git；`.env` 永不进 Git；`reference/` 第三方克隆不进仓；单文件 >100MB 不进 GitHub
- Agnes 历史泄露 key：**用户裁定接受、不轮换**（勿列为方案待办，勿反复提示）
- 分工定版：**此后代码修改=GPT 任务**（在 A 仓分支进行）；执行侧 Claude=推送/验证/回归/归档；用户=验收裁决
