# 01 系统介绍（供无上下文 agent 阅读）

## 这是什么系统

一套 **AI 驱动的动画短片生产流水线**（项目名 `animation-storyboard`，内部称 Agent System V2）：输入 YAML 剧本，由多智能体系统编排产出角色设定图、分镜首帧、逐镜视频、配音音效，最终 ffmpeg 合成成片。

- **后端**：Python FastAPI（端口 8000，入口 `api_server.py`，8 组 routers）
- **前端**：Vue/Vite（端口 7777）
- **媒体生成**：Agnes API 三模态（文本 `agnes-3.0-flash` / 生图 `agnes-image-2.1-flash` / 生视频 `agnes-video-2.5-flash`），国内直连；密钥全部经环境变量引用（config 内只有 `${ENV_VAR}` 占位符）
- **图片公网化**：GitHub Pages 图床（`agnes-frame-host`）为主，imgbb 回退
- **其他**：TTS/旁白 MiniMax 与 edge-tts；抠图 rembg；合成 ffmpeg

## 多智能体体系

Resource Agent（角色/道具/场景资产）→ Scene Agent（场景锚点/多视角）→ Director Agent（分镜/镜头绑定/审查）→ Assembly Agent（成片装配）+ Sequence 域（拼接/音频混合）+ Producer（多镜智能协调/并发调度）+ 独立测试/审核流水线。经 Phase 1-56 共五十余个阶段演进，每阶段有 FINAL 报告归档（将推送至 C 档案仓）。

## 测试与质量（与本次迁移直接相关）

- **pytest 全量 mock 回归：约 2847 项，全假服务、零 API 配额、可离线运行**——这是 GitHub Actions 云端测试可行的前提
- 存在已知失败基线（GPT 交接包记录约 291 项已知失败/错误），CI 初期应做「回归对照报告」（失败数 ≤ 基线即视为无回退），而非硬门禁
- 人评（看片验收）不可自动化，始终由用户完成

## 运行环境

- Windows 11 本机；Python 3.10+（本机解释器在非标准路径）；依赖 fastapi/uvicorn/httpx/pytest 等（**依赖清单需在 CI 接入时从本机 `pip freeze` 固化**）
- 外网访问 GitHub 依赖 **Steam++（Watt Toolkit）加速**——实测不开加速时 `github.com`/`api.github.com` 全部超时，开启后 200（详见 02 §网络）
