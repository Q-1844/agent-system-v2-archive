# Phase 53｜剧情夹具与看片要求

## 使用方法

这是创作简报和测试负荷要求，系统 Agent 自主发展剧本、分镜和技术选择。下面列的是必须发生的叙事事件，**不是指定首帧、尾帧或 reference 的逐镜答案**。六镜为本轮夹具目标，正式 Skill 的故事段和镜头数规则不变。

统一采用当前已经可工作的写实风格与画幅，批准对应风格的角色参考后再生成。每片有起因、发现、选择和结果；不要做六个互不相关的漂亮画面。源时长按冻结基线执行，成片目标约三十至四十二秒，以完整关键过程优先。

沿用现有身份、环境连续性、重大不合理三类自动审查及既有放行/修复政策。下述项目专属事实作为剧情负荷核验和用户看片依据，同等作用于 A/B，不偷偷增加一组的自动审查次数。

不加画外旁白或主动背景音乐；保留合格原生环境音和音效。室内允许且要求简短人物对白，另外两片以动作为主、允许短交流。检查实际声轨，不能把近似静音写成音效保留。若原生对白不可靠，保留失败，不用未经约定的配音或字幕把该项包装成通过；已有合法音频修复若被选用，A/B 同政策且单独记耗时与干预。

角色、道具和环境细节由 Agent 完成并审批，以下只是可用于批准资源的起点。

## I｜《杯沿的断层》：室内对白与细动作（主对照题）

地点：傍晚的古生物研究室。一张木桌、标本托盘、茶具和窗侧柜，三个研究人员围坐。故事围绕一个虚构标本的裂纹争论：它看似支持某个旧判断，却发现修补痕迹，三人决定重新核验。

可用人物起点：负责人林澄、年轻研究员周野、负责标本保存的顾宁。三人年龄/发型/服装轮廓有明确区分；不靠姓名字幕辨识身份。科学讨论使用虚构标本和推测，不把编造内容讲成真实古生物学结论。

关键道具：一只带小缺口、特定把手方向的茶杯；一件固定形态标本。三人各有稳定座位，茶杯起始在周野一侧。

六个叙事负荷：

1. 交代三人、研究室、座位、标本和茶杯起始位置。
2. 林澄指出标本裂纹，提出简短推测；说话者明确。
3. 周野拿起茶杯，提出反问。拿起过程与茶杯归属可见，杯子不能瞬移到另一人手上。
4. 顾宁指出修补痕迹；视线和指向确实落在标本上。
5. 周野把茶杯放回桌面，林澄改变判断；关键放下过程保留。
6. 三人达成重新核验的决定，标本及茶杯最终状态符合此前动作。

允许正常正反打与机位变化，是否使用视频接续由 Agent 按规则决定。对白不求长，把每轮意思讲清即可。至少覆盖两个明确说话者，第三人需有独立叙事作用。不要用远景加画外对白代替全部人物表演。

看片重点：三人是否串身份/衣服/座位；说话轮次是否和人物一致；茶杯抓握、拿起、落桌、把手、数量；视线及标本位置；正常切镜能否保持空间关系。口型/声线问题单列，不因动作小就降低身份和接触要求。

## F｜《灰塔的错误信号》：悬疑战争与要塞进攻

地点：虚构战争中的山口要塞。两名突击队员在进攻前发现约定信号异常。他们必须接近外侧控制点并开启闸门，行动中发现信号由守军伪造，最终切断假信号并取得进攻入口。

角色与场景起点：队长和通信员，两人装备外形明确区分；一名守军可短暂出现。突出队员身份，不把远处群体作为主任务。资源包括同一要塞入口、控制箱、信号灯、通信设备；首次批准时确定墙体、入口方向、掩体位置和闸门状态。

六个叙事负荷：

1. 明确要塞、封闭入口、掩体与队员位置。
2. 通信员看到异常信号，队长决定靠近控制点。
3. 两人向指定掩体移动，行动方向可解释。
4. 遭遇守军阻拦，队长掩护通信员接近控制箱；行为有因果，不只做爆炸空镜。
5. 通信员操作装置切断假信号，闸门开始打开；操作及结果应保留。
6. 两人进入已打开的入口，后续进攻具备条件，悬疑线索得到回应。

看片重点：位置/方向、掩体和要塞结构、装备与手部接触、队员人数、装置操作、闸门从闭到开的状态。允许战场气氛，但不要用大量群众和持续爆炸放大无关难度。角色/资源准备耗时和模型动作失败分开记录。

## M｜《第三道回声》：怪物区域与探索

地点：有异常生物活动的地下标本库。两名探索者进去找回记录匣，听到第三道回声。他们误以为同伴落后，直到同伴从前方回答，才意识到怪物正在模仿脚步。

角色与资源起点：两名外形清楚的探索者；一种固定外形的怪物，出现时最多一个个体。重要道具为手电和记录匣；场景包括入口走廊与相连的标本库，以红色管道和一道防护门建立空间记忆。

六个叙事负荷：

1. 两人进入走廊，交代手电归属、标志物和前进方向。
2. 听到额外脚步，一人回头确认同伴位置。
3. 正常转入相邻标本库，找到记录匣；无需强迫所有换机位都硬接尾帧。
4. 怪物出现在可解释的位置，模仿脚步的线索成立。
5. 两人带着记录匣撤向防护门，一人操作关门；关键动作和接触可见。
6. 门关闭、两人及记录匣均在安全一侧；门外再响起第三道回声，形成悬疑结尾。

看片重点：角色身份、怪物形态与数量、光源方向、管道/门/走廊布局、手电和记录匣归属、撤退方向、关门结果。低照度是剧情氛围，不能以黑屏隐藏关键动作或画面错误。

## 共同负荷核验

生成前记录每片的关键事件、角色/道具初态和终态；批准后冻结。生成后逐项确认，失败留在表里。

| 核验项 | 合格条件 |
| --- | --- |
| 剧情完成 | 关键事件全发生，因果、发现与结尾可理解 |
| 身份 | 同一角色及怪物的主要特征保持，人数符合计划 |
| 场景 | 空间和物件状态可解释；切镜本身不算错误 |
| 接触 | 茶杯、装置、手电、记录匣、门的关键接触完整 |
| 剪辑 | 保留关键动作，不通过删掉交接/操作结果把失败伪装为可用 |
| 接续 | 使用真正被保留区间的末帧；如果只是参考/重建首帧，诚实标注 |
| 音频 | 保留实际合格音效；室内对白和说话者一致，问题单列 |
| 审核 | 相同 gate 与返工政策，有具体版本和裁切区间的审查依据 |

用户看片时尽量隐藏 A/B 标签并改变播放顺序，提供成片与必要源镜，收集“可接受/不可接受及具体时间点”。未看片不写用户接受；自动审核通过不等于审美合格。
