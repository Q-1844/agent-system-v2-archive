验证覆盖：

- 探索基线不充当复用准备成果的配对 A；每区组恰含一个 A、一个 B，顺序含 AB 与 BA。
- 新会话、输入只读复制、被测媒体重新生成、生产代码和正式 Skill 不修改。
- 人工等待区间的重叠、相邻、零长度、越界、缺终点；无效负区间拒绝。
- 前置资源/审批的最晚就绪时刻；缺事件保持未知，提交早于就绪须查错。
- 已知任务恢复查询；未知提交不自动补交；查找无结果不等同于可安全重发。
- 枚举三种 actor 与授权、加载、隐式委派、绕过标记的组合：Skill 加载不自动等于后端业务授权，隐式委派不算同主体执行。
- 枚举任务 ID、提交是否不明和对账结果：不明提交始终先对账。
- 上游未选候选不自动影响旧选版；正式换选后复核 freshness；接力端点跟随实际裁切末帧。
- 重复回执按 task ID 去重；失败仍在总分母，零基线/缺测/改变负荷不生成虚假节省比例。
- 配对改善比例先逐对计算、中位数再汇总，并用 B=A×(1−改善比例) 反算。
- 互斥时间分类反算总观察窗；并行节点时长不能直接相加为墙钟总耗时。
- UTF-8 内容和本地 Markdown 引用可读取；开工提示词与执行范围一致。

合成数据只用于检查这些定义和边界，没有填进真实效率结论。百分之十五是拟议工程继续验证目标，已经核验计算口径；它不代表预计一定提速，更不代表统计证明。
