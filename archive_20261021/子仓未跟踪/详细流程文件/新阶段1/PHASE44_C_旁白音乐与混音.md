# Phase 44C｜MiniMax 旁白、连续音乐与混音

可整段交 zcode。前置：B 批次交付了可复现时间线和音轨 cue 契约。接口审计、假响应测试、音乐素材准备可提前进行；真实声音接线以 B 的时间线版本为输入。

## 可直接执行的任务书

你的目标是给基础成片 Agent 增加**少量恰当的画外旁白**与一条贯穿作品的背景音乐，并导出可听清叙事、可追溯分轨的成片。用户说系统中已有 MiniMax 语音 API；先审计现有后端适配器、密钥位置、调用权限、账户对应地域、声音资产、SDK/HTTP 方式和错误处理，复用已有能力。不要读取或输出实际密钥，不在前端发起带密钥请求。文档示例中的官方模型/字段是核验入口，不预设本账户实际可用。

### C0. 声音策略和素材身份

制作一个清晰的分轨计划：`video_original`、`narration`、`music`；必要时保留原生环境声而关闭每镜自带音乐。原画面已能讲清的动作可以留无声或音乐，不要求每镜都配旁白。旁白只补充故事信息、情绪和必要的场景转换；不要用大量解说覆盖视觉动作。每句必须有文字稿、`voice_id`、语速/情感参数、开始时间、音频版本与来源回执；用户可单独试听和修改，再局部重合成。

音乐 v1 优先从用户已拥有、许可明确、可下载的**一条器乐素材**接入；若系统已有音乐资产库可复用。没有合适素材时先用合法测试音乐或静音完成管线，不为了完成测试擅自生成/购买/使用来路不明的歌曲。音乐应跨镜连续铺底，片头片尾淡入淡出；长度不足时提供明示的循环/延长/替换方案，避免重复点的拍子突变。自动音乐生成可作为后续单独批次，不与 TTS 接线捆绑。

### C1. MiniMax 适配器最小闭环

1. 基于**系统现有账户的官方地域端点和有效模型**，先做一条短旁白的真实小样。官方同步 T2A v2 示例为 `POST /v1/t2a_v2`，请求有 `model`、`text`、`voice_setting.voice_id`、`audio_setting`；非流式可收 hex 或时效 URL。实际端点、可用模型及声线由当前配置核实。
2. 响应同时检查 HTTP 状态、`base_resp.status_code`、`data` 非空、音频可解码、时长合理、`trace_id`；不能把 HTTP 200 当声音生成成功。URL 返回时及时下载到受管资产并计算哈希，不能依赖 24 小时有效期做长期复现。长文本才考虑异步任务及轮询；第一版逐句短文本用同步或既有服务。
3. voice_id/模型/速度/语言/输入文本必须留版本，重试同一 cue 使用幂等键/缓存；断线恢复查已有任务或已下载资产，避免重复付费。保存请求参数摘要、供应商 trace、音频哈希和脱敏错误体；不记录密钥。
4. 单句试听检验音色、普通话发音、停顿和情绪；旁白文本改动只重合成该句，不改视频镜头。若有既有声线库，采用经批准的 narrator；不得默认启动声音克隆或把角色声线绑给旁白。

### C2. 旁白落点与时间约束

Agent 从故事段和时间线提出 3–6 个**候选** cue（数量随作品而定，不是强制 KPI），每 cue 写“为什么这里需要说、画面留出的听觉空间、文字稿、预估时长”。TTS 实测时长回来后重新排 cue，不通过加速视频/截断音节来硬塞；避免在短镜切点上截断句尾。若一条旁白比可用窗口长，优先改短文案、移动到邻近空隙，或提交用户选择；不让 TTS 音频盖到不相干的下一个剧情状态。可保留无旁白版本作 A/B 试听。

### C3. 混音与量化验证

对齐采样率/声道，精确放置 cue。音乐在旁白期间做平滑 ducking，在句尾恢复；原生环境声若保留，要先审听其内容，再选择与 BGM 并存或压低。`amix` 可混轨，`sidechaincompress` 可作旁白触发的音乐压低，`loudnorm` 可做终混响度规范；参数要试听调整并存入 render profile。不要把给音乐降低的电平误当成最终峰值无削波验证。输出至少包含：有旁白+音乐的完整版、静音画面基线、旁白独立轨、音乐独立轨、完整文案和时间码。

测量：片头/片尾及每句上下文试听，报告真峰值、响度/动态范围（按目标播放平台设目标并注明，不硬编码某一全平台通用 LUFS）、剪切/削波和声画总时长差。自动测量不能替代人耳验收；请用户重点听旁白是否有用、声线是否合适、配乐是否干扰叙事、跨镜是否连续。

### C4. 故障与回归

测试空 TTS 数据、供应商错误码、网络超时、错误 voice_id、短 URL 过期、音乐不足片长、原视频无音轨/有原生音乐、cue 覆盖切点、中途渲染失败。对同一快照重复渲染，确认音频版本固定且输出可复现；失效时保留 B 的无声预览与错误报告，不静默丢旁白后宣称完整成片。验证用户换文案/声线、换音乐素材只生成新音频/成片版本，原版可回看。

### C5. 交付

提交 `PHASE44_C_REPORT.md`：配置审计（脱敏）、最小 TTS 请求与回执、旁白逐句表、素材许可证/来源字段、时间线版本、混音参数与测量、失败测试、可直接播放的两种成片和分轨链接、Agent 提案到用户修改的审查方式。只有用户听过并选择、且正式快照全部通过，才标“正式成片”；否则标工程预览。
