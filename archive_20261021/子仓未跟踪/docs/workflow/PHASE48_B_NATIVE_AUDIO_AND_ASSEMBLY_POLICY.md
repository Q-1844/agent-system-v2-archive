# Phase48 B：原生音效保留与装配政策

先读 [总控计划](PHASE48_00_REVIEW_RESEARCH_AND_BATCH_PLAN.md) 和 A 批交接。目标是让装配 Agent 保留合格原生环境声与动作声，并消除“没有音乐就整条静音”的处理。

## 输入与边界

使用 A 批冻结素材及新增的代表性镜头。读取装配 Agent 的正式角色政策、Sequence/混音契约和工具权限。历史记录提示装配可能不能直接绑定正式 Skill，必须核对当前注册表：支持则走正式绑定；不支持则修改现有角色政策和装配契约，不假造绑定成功，不新增一套旁路。

全部测试禁止旁白。人物对白另标记，B 验证是否正确保留，D 验证说话人、台词和声线。不要以本批为由恢复默认旁白或新增 TTS 解说。

## 素材分类

| 音频情况 | 默认处理 | 必查内容 |
|---|---|---|
| 合格环境声与动作声，没有音乐 | 保留原音并按需要调整增益 | 动作同步、接缝、噪声与削波 |
| 环境声与动作声叠有原生音乐 | 按作品音乐政策评估 | 是否串曲、突断、遮蔽对白 |
| 画面内人物对白 | 原音候选保留，交 D 验收 | 台词、说话人、可懂度、声线 |
| 意外旁白、乱语或不可接受音频 | 标记不合格并提出局部修复 | 不用整片静音掩盖失败 |
| 无音轨或实际静音 | 如实记录，按镜头需要决定 | 不把“保留音效”写成已实现 |

一个混合音轨不等于可直接取得独立对白、音乐和音效。若需要分离，应记录实际工具与分离伪影；不能在契约中捏造不存在的 stems。

## 执行步骤

1. 对输入执行真实媒体检查并试听，分别记录是否有旁白、对白、环境声、动作声和音乐。用户观察到的模型变化只作为待验证假设。
2. 沿现有装配契约明确原音保留、必要静音、增益、外部音乐、淡入淡出和替换音轨的语义；展示使用了哪些实际音轨，不新增第二份 canonical 真相。
3. 修正装配角色政策：默认保留合格音效；禁止自动旁白；外部音乐由作品要求决定，不为每镜机械加一首不同音乐。需处理坏音频时先提出能保住好素材的方案。
4. 使用系统 Agent 正式入口制作候选。保留原音基线与修改版，记录每个剪辑点的音频处理；不能仅用执行脚本证明 Agent 自主装配完成。
5. 检查成片音画时序、总时长、音轨存在性、接缝突响、削波、对白可懂度及听感。技术检查通过后仍需试听。
6. 演练一次刷新或中断后的结果对账，确认返回的成片版本、实际素材与 canonical 一致。

## 验收素材与失败处理

覆盖：纯动作音效、持续环境声、混有音乐、有人物对白、无音轨，以及音效中夹入意外旁白。对已有合格素材可复用；缺少代表性素材时通过导演正式路径生成。音量或波形不能独立证明“无旁白”，需实际试听。

禁止把有旁白的混合轨自动归为通过，禁止因去音乐失败而静音整部作品。修复可以选择局部静音后补合格环境声、重新生成该镜头声音、保留原片并单独制作音轨；每种都要写清实际损失和依赖。

## 交付与继续

交付 `PHASE48_B_REPORT.md`、角色政策/契约 diff、输入音频标签表、原版与修改版可播放成片、真实 Agent 轨迹和未解决问题。音效保留与禁止旁白均有实际证据后，进入 C/D。若特定音频路由失败，明确阻塞那条路由，其余有效实验继续。
