## 📌 项目现状（v2.0 · 2026-07-29）

### A. 项目是什么

这是一个 **AI 视频编辑器**：用户输入剧本 → AI 自动生成角色三视图、分镜图、动态视频、配音 → ffmpeg 合成最终有声 mp4。整套流程在一个 Web 编辑器里完成，目标是"一套流程下来做出有剧本的有声视频"。

**核心 AI 服务**：
- **Agnes AI**（Sapiens AI）：文本理解 + 文生图/图生图 + 图生视频（需 Clash 代理）
- **edge-tts**（微软）：TTS 语音合成（免费，替代过期的 Mimo）
- **rembg**：本地背景移除（抠图，isnet-anime 动漫模型）
- **ffmpeg**：本地视频合成（Ken Burns + 拼接 + 混音）

### C. 完整视频生成流程（6 步，端到端）

> 这是项目的核心。每步说明前端操作、后端接口、数据流、输出。

**步骤 1：剧本编辑**
- 前端 `/script-editor` 填项目信息 + 角色列表（英文描述作生图提示词）+ 场景列表（中文描述 + 镜头/光照/动作/对白）
- 后端 `POST /api/project/{p}/script` 保存 YAML 到 `input/{p}.yaml` + 调 ScriptParser 生成 `parsed_script.json`
- 输出：`output/parsed_script.json`（含 project/characters/scenes）

**步骤 2：角色生成与绑定**
- 前端 `/characters` 用三种方式生成三视图：单个生成 / 链式生成（正面→参考正面生成侧面/背面）/ 设定图生成（一张横图三等分）。每张自动 rembg 抠图
- 点「绑定到项目」→ 后端 `POST /api/project/{p}/character/bind` 落盘三视图到 `output/characters/{name}_{view}.png` + 写 `parsed_script.json` 的 `reference_images`
- 作用：分镜生成时取角色 front 图作参考，保持角色一致性

**步骤 3：分镜生成**
- 前端 `/storyboard` 选场景点「生成分镜」
- 后端 `POST /api/project/{p}/scene/{id}/generate-storyboard`（后台任务）：取场景角色 front 图作 image_refs → 调 Agnes 图生图 → 存 `output/storyboards/scene_{id}.png` → 写回 `image_path` → SSE 推送进度
- 前端 useTaskStream 订阅 SSE，完成后刷新显示

**步骤 4：视频生成（Agnes 图生视频）⚠️ 待完成**
- 前端 `/animation`（生成入口待补）
- 后端待做：用分镜图的公网 URL 作 `image` 参数 → 调 `agnes_client.generate_video`（ti2vid，121帧/24fps≈5秒）→ 轮询 video_id → 下载存 `output/videos/scene_{id}.mp4` → 写回 `video_path`
- Agnes 视频 API 要点：`POST /v1/videos` 异步任务；完成后视频 URL 走 `remixed_from_video_id -> url -> video_url` fallback 链（`.cn` 直生成任务 `remixed_from_video_id` 为 null，URL 在 `url` 字段）；`image` 要公网 URL（用 Agnes 图片返回的 URL）；num_frames 必须 8n+1；**视频静音**

**步骤 5：配音生成（edge-tts）**
- 前端 `/audio` 选音色（晓晓/云希等）+ 语速，点 Generate All
- 后端 `POST /api/project/{p}/audio/{id}/generate`（后台任务）：调 EdgeTTSClient.synthesize → 存 `output/audio/dialog_{id}.mp3` + 生成 `output/subtitles/scene_{id}.srt` → 写回 `audio_path`/`subtitle_path`

**步骤 6：合成导出（ffmpeg）**
- 前端顶栏「导出视频」
- 后端 `POST /api/project/{p}/compose` → VideoComposer：每场景有 video_path 用视频段，否则用分镜图做 Ken Burns（zoompan 推拉）→ concat 拼接 → 叠加音频（adelay 偏移 + amix + apad 延伸到视频长度）→ 输出 `output/final.mp4`
- 前端 SSE 订阅进度，完成后自动下载

**当前能跑通的链路**：剧本 → 角色绑定 → 分镜(待Agnes) → 配音(edge-tts) → 合成(Ken Burns+音频) → final.mp4。已用「我的动画短片」素材合成出 12 秒含音视频的 final.mp4。Agnes 通了后，Ken Burns 升级为真正的 AI 动态视频。

## 1. 项目概述

### 1.1 项目目标

构建一个**交互式动画分镜工作流系统**，能够：

- 从剧本/故事文本自动生成动画分镜
- 保持角色一致性和风格统一
- 生成过渡动画和最终视频
- **每一步都可查看结果，不满意可重新生成**

### 1.2 核心特点

| 特点 | 说明 |
|------|------|
| **交互式执行** | 每个阶段完成后暂停，用户确认后继续 |
| **择优继续** | 每步生成多个候选，自动评估选择最佳 |
| **可重试** | 任何步骤不满意都可以重新执行 |
| **进度可视化** | 实时显示当前进度和中间结果 |
| **模块化设计** | 各阶段独立，可单独调试 |

### 1.3 技术栈

| 组件 | 技术选择 | 说明 |
|------|----------|------|
| **前端框架** | Vue 3.5 + TypeScript | Web 编辑器 |
| **UI 组件** | Naive UI 2.40 | 通知/对话框/表单（与手写SCSS混合） |
| **状态管理** | Pinia 2.2 | 全局状态 |
| **构建工具** | Vite 5.4 + UnoCSS | 热更新 |
| 后端框架 | FastAPI | REST API |
| 语言 | Python 3.10+ | 后端主语言 |
| HTTP客户端 | httpx | 异步调用API（支持proxy） |
| 图像处理 | Pillow + rembg | 图片处理 + 抠图(isnet-anime) |
| 视频合成 | ffmpeg (subprocess) | Ken Burns + 拼接 + 混音 |
| 语音合成 | edge-tts | 免费 TTS（替代过期的 Mimo） |
| 配置管理 | PyYAML | YAML配置解析 |
| 实时进度 | SSE (Server-Sent Events) | 替代前端轮询 |

### 2.3 多项目管理

系统支持同时管理多个项目，每个项目完全独立：

```python
class ProjectManager:
    """项目管理器"""
    
    def __init__(self, base_dir: str = "./projects"):
        self.base_dir = Path(base_dir)
        self.base_dir.mkdir(parents=True, exist_ok=True)
    
    def create_project(self, name: str) -> Path:
        """创建新项目"""
        project_dir = self.base_dir / name
        project_dir.mkdir(exist_ok=True)
        
        # 创建标准目录结构
        (project_dir / "input").mkdir(exist_ok=True)
        (project_dir / "output" / "characters").mkdir(parents=True, exist_ok=True)
        (project_dir / "output" / "storyboards").mkdir(parents=True, exist_ok=True)
        (project_dir / "output" / "videos").mkdir(parents=True, exist_ok=True)
        (project_dir / "output" / "audio").mkdir(parents=True, exist_ok=True)
        (project_dir / "output" / "subtitles").mkdir(parents=True, exist_ok=True)
        (project_dir / "cache" / "checkpoints").mkdir(parents=True, exist_ok=True)
        
        return project_dir
    
    def list_projects(self) -> list:
        """列出所有项目"""
        return [d.name for d in self.base_dir.iterdir() if d.is_dir()]
    
    def get_project_dir(self, name: str) -> Path:
        """获取项目目录"""
        project_dir = self.base_dir / name
        if not project_dir.exists():
            raise FileNotFoundError(f"项目不存在: {name}")
```

```python
# src/utils/logger.py
import logging
from datetime import datetime
from pathlib import Path

def setup_logger(name: str, log_dir: str = "./logs") -> logging.Logger:
    """
    设置日志记录器
    
    Args:
        name: 日志记录器名称
        log_dir: 日志目录
    
    Returns:
        配置好的日志记录器
    """
    # 创建日志目录
    Path(log_dir).mkdir(parents=True, exist_ok=True)
    
    # 创建日志记录器
    logger = logging.getLogger(name)
    logger.setLevel(logging.DEBUG)
    
    # 避免重复添加处理器
    if logger.handlers:
        return logger
    
    # 文件处理器
    log_file = f"{log_dir}/{datetime.now().strftime('%Y%m%d_%H%M%S')}.log"
    file_handler = logging.FileHandler(log_file, encoding='utf-8')
    file_handler.setLevel(logging.DEBUG)
    
    # 控制台处理器
    console_handler = logging.StreamHandler()
    console_handler.setLevel(logging.INFO)
    
    # 格式化器
    formatter = logging.Formatter(
        '%(asctime)s - %(name)s - %(levelname)s - %(message)s'
    )
    file_handler.setFormatter(formatter)
    console_handler.setFormatter(formatter)
    
    logger.addHandler(file_handler)
    logger.addHandler(console_handler)
    
    return logger
```

### 5.2 进度追踪工具

```python
# src/utils/progress.py
import json
from datetime import datetime
from pathlib import Path
from typing import Optional

class ProgressTracker:
    """进度追踪器"""
    
    def __init__(self, project_dir: str):
        self.project_dir = Path(project_dir)
        self.progress_file = self.project_dir / "progress.json"
        self.data = self._load()
    
    def _load(self) -> dict:
        """加载进度"""
        if self.progress_file.exists():
            try:
                with open(self.progress_file, 'r', encoding='utf-8') as f:
                    return json.load(f)
            except json.JSONDecodeError:
                return self._create_default()
        return self._create_default()
    
    def _create_default(self) -> dict:
        """创建默认进度结构"""
        return {
            'project_name': self.project_dir.name,
            'created_at': datetime.now().isoformat(),
            'updated_at': datetime.now().isoformat(),
            'stages': {}
        }
    
    def save(self):
        """保存进度"""
        self.data['updated_at'] = datetime.now().isoformat()
        self.project_dir.mkdir(parents=True, exist_ok=True)
        with open(self.progress_file, 'w', encoding='utf-8') as f:
            json.dump(self.data, f, ensure_ascii=False, indent=2)
    
    def update_stage(self, stage_name: str, status: str, **kwargs):
        """
        更新阶段状态
        
        Args:
            stage_name: 阶段名称
            status: 状态 ('pending', 'in_progress', 'completed', 'failed')
            **kwargs: 其他数据
        """
        if stage_name not in self.data['stages']:
            self.data['stages'][stage_name] = {}
        
        self.data['stages'][stage_name].update({
            'status': status,
            'updated_at': datetime.now().isoformat(),
            **kwargs
        })
        
        self.save()
    
    def get_stage(self, stage_name: str) -> dict:
        """获取阶段状态"""
        return self.data['stages'].get(stage_name, {})
    
    def get_progress(self) -> dict:
        """获取整体进度"""
        stages = self.data.get('stages', {})
        total = len(stages)
        completed = sum(1 for s in stages.values() if s.get('status') == 'completed')
        
        return {
            'total': total,
            'completed': completed,
            'percentage': (completed / total * 100) if total > 0 else 0
        }
```

### 5.4 择优继续实现

```python
import random
from typing import Optional, List, Dict

class BestOfNGenerator:
    """
    择优继续生成器
    生成N个候选，评估并选择最佳
    """
    
    def __init__(
        self, 
        api_client, 
        evaluator, 
        n_candidates: int = 3, 
        threshold: float = 7.0,
        max_retries: int = 3
    ):
        self.api_client = api_client
        self.evaluator = evaluator
        self.n_candidates = n_candidates
        self.threshold = threshold
        self.max_retries = max_retries
    
    async def generate(
        self, 
        prompt: str, 
        references: List[str], 
        retry_count: int = 0,
        **kwargs
    ) -> dict:
        """
        生成最佳结果
        
        Args:
            prompt: 生成提示词
            references: 参考图列表
            retry_count: 当前重试次数
            **kwargs: 其他参数
        
        Returns:
            dict: 最佳候选结果
        """
        candidates = []
        
        # Step 1: 多变体生成
        for i in range(self.n_candidates):
            seed = random.randint(1000, 9999)
            try:
                result = await self.api_client.generate_image(
                    prompt=prompt,
                    image_refs=references,
                    seed=seed,
                    **kwargs
                )
                candidates.append({
                    'url': result['url'],
                    'seed': seed,
                    'index': i
                })
            except Exception as e:
                print(f"警告: 候选 {i + 1} 生成失败: {e}")
                continue
        
        if not candidates:
            raise Exception("所有候选生成失败")
        
        # Step 2: 自动评估
        scored_candidates = []
        for candidate in candidates:
            try:
                score = await self.evaluator.evaluate(
                    image_url=candidate['url'],
                    criteria={
                        'prompt': prompt,
                        'references': references
                    }
                )
                candidate['score'] = score
                scored_candidates.append(candidate)
            except Exception as e:
                print(f"警告: 候选评估失败: {e}")
                continue
        
        if not scored_candidates:
            raise Exception("所有候选评估失败")
        
        # Step 3: 选择最佳
        best = max(scored_candidates, key=lambda x: x['score']['total'])
        
        # Step 4: 质量检查
        if best['score']['total'] < self.threshold:
            if retry_count >= self.max_retries:
                print(f"警告: 已达到最大重试次数({self.max_retries})，返回当前最佳结果")
                return best
            
            enhanced_prompt = self._enhance_prompt(prompt, best['score'])
            print(f"质量不达标 ({best['score']['total']:.1f}/{self.threshold})，正在优化prompt重试...")
            return await self.generate(enhanced_prompt, references, retry_count + 1, **kwargs)
        
        return best
    
    def _enhance_prompt(self, prompt: str, score: dict) -> str:
        """
        根据评估结果优化prompt
        
        Args:
            prompt: 原始prompt
            score: 评估结果
        
        Returns:
            优化后的prompt
        """
        suggestions = score.get('suggestions', '')
        
        # 根据低分维度添加针对性优化
        enhancements = []
        if score.get('character', 10) < 7:
            enhancements.append("detailed character features")
        if score.get('style', 10) < 7:
            enhancements.append("consistent art style")
        if score.get('composition', 10) < 7:
            enhancements.append("better composition")
        if score.get('clarity', 10) < 7:
            enhancements.append("high detail, sharp focus")
        
        enhancement_str = ", ".join(enhancements) if enhancements else ""
        
        if suggestions:
            enhanced = f"{prompt}, {suggestions}, {enhancement_str}, masterpiece, best quality"
        else:
            enhanced = f"{prompt}, {enhancement_str}, masterpiece, best quality"
        
        return enhanced
```

```python
import asyncio
import base64
import httpx
from typing import Optional, List, Dict

class AgnesClient:
    """Agnes API客户端"""
    
    def __init__(self, config: dict):
        self.config = config
        self.base_url = config['base_url']
        self.api_key = config['api_key']
        self.headers = {
            'Authorization': f'Bearer {self.api_key}',
            'Content-Type': 'application/json'
        }
        self.max_retries = config['settings']['image'].get('max_retries', 3)
        self.timeout = config['settings']['image'].get('timeout', 60)
    
    async def generate_image(
        self, 
        prompt: str, 
        image_refs: Optional[List[str]] = None, 
        seed: Optional[int] = None,
        **kwargs
    ) -> dict:
        """
        生成图片
        
        Args:
            prompt: 生成提示词
            image_refs: 参考图URL列表
            seed: 随机种子
            **kwargs: 其他参数
        
        Returns:
            包含图片URL的字典
        
        Raises:
            Exception: API调用失败
        """
        data = {
            'model': self.config['models']['image'],
            'prompt': prompt,
            'size': kwargs.get('size', self.config['settings']['image']['size']),
            'extra_body': {
                'response_format': 'url'
            }
        }
        
        if image_refs:
            data['extra_body']['image'] = image_refs
        
        if seed:
            data['seed'] = seed
        
        async with httpx.AsyncClient() as client:
            for attempt in range(self.max_retries):
                try:
                    response = await client.post(
                        f'{self.base_url}/v1/images/generations',
                        headers=self.headers,
                        json=data,
                        timeout=self.timeout
                    )
                    
                    if response.status_code == 200:
                        return response.json()
                    elif response.status_code == 429:  # 速率限制
                        wait_time = 2 ** attempt * 5  # 指数退避
                        print(f"速率限制，等待 {wait_time}秒后重试...")
                        await asyncio.sleep(wait_time)
                    else:
                        raise Exception(f"API错误: {response.status_code} - {response.text}")
                        
                except httpx.TimeoutException:
                    if attempt == self.max_retries - 1:
                        raise Exception(f"API调用超时，已重试{self.max_retries}次")
                    print(f"超时，正在重试 ({attempt + 1}/{self.max_retries})...")
                    await asyncio.sleep(2)
            
            raise Exception("图片生成失败")
    
    async def generate_video(
        self, 
        prompt: str, 
        image_refs: List[str], 
        mode: str = 'keyframes',
        **kwargs
    ) -> dict:
        """
        生成视频
        
        Args:
            prompt: 生成提示词
            image_refs: 参考图URL列表
            mode: 生成模式 ('keyframes' 或 'ti2vid')
            **kwargs: 其他参数
        
        Returns:
            包含视频URL的字典
        
        Raises:
            Exception: API调用失败或超时
        """
        data = {
            'model': self.config['models']['video'],
            'prompt': prompt,
            'extra_body': {
                'image': image_refs,
                'mode': mode
            },
            'num_frames': kwargs.get('num_frames', self.config['settings']['video']['num_frames']),
            'frame_rate': kwargs.get('frame_rate', self.config['settings']['video']['frame_rate'])
        }
        
        max_retries = self.config['settings']['video'].get('max_polling_retries', 180)
        polling_interval = self.config['settings']['video']['polling_interval']
        
        async with httpx.AsyncClient() as client:
            # 创建任务
            try:
                response = await client.post(
                    f'{self.base_url}/v1/videos',
                    headers=self.headers,
                    json=data,
                    timeout=60
                )
                
                if response.status_code != 200:
                    raise Exception(f"创建视频任务失败: {response.status_code} - {response.text}")
                
                task_data = response.json()
                video_id = task_data['video_id']
                
            except httpx.TimeoutException:
                raise Exception("创建视频任务超时")
            
            # 轮询等待完成
            for retry_count in range(max_retries):
                await asyncio.sleep(polling_interval)
                
                try:
                    result = await client.get(
                        f'{self.base_url}/agnesapi?video_id={video_id}',
                        headers=self.headers,
                        timeout=30
                    )
                    status_data = result.json()
                    
                    if status_data['status'] == 'completed':
                        return status_data
                    elif status_data['status'] == 'failed':
                        raise Exception(f"视频生成失败: {status_data.get('error')}")
                    
                    # 显示进度 (每30秒显示一次)
                    if retry_count % 6 == 0:
                        elapsed = (retry_count + 1) * polling_interval
                        print(f"等待中... 已等待 {elapsed}秒 ({elapsed // 60}分{elapsed % 60}秒)")
                        
                except httpx.TimeoutException:
                    print(f"轮询超时，继续等待...")
                    continue
            
            raise Exception(f"视频生成超时: 超过最大等待时间 {max_retries * polling_interval}秒 ({max_retries * polling_interval // 60}分钟)")


class MimoTTSClient:
    """Mimo TTS客户端"""
    
    def __init__(self, config: dict):
        self.config = config
        self.base_url = config['base_url']
        self.api_key = config['api_key']
        self.headers = {
            'Authorization': f'Bearer {self.api_key}',
            'Content-Type': 'application/json'
        }
    
    async def synthesize(self, text: str, voice: str = 'default', speed: float = 1.0) -> bytes:
        """
        语音合成
        
        Args:
            text: 要合成的文本
            voice: 语音类型
            speed: 语速
        
        Returns:
            音频数据 (bytes)
        
        Raises:
            Exception: API调用失败或返回格式错误
        """
        data = {
            'model': self.config['models']['tts'],
            'messages': [
                {'role': 'user', 'content': text},
                {'role': 'assistant', 'content': ''}
            ]
        }
        
        async with httpx.AsyncClient() as client:
            for attempt in range(3):  # 最多重试3次
                try:
                    response = await client.post(
                        self.base_url,
                        headers=self.headers,
                        json=data,
                        timeout=30
                    )
                    
                    if response.status_code != 200:
                        if response.status_code == 429:
                            wait_time = 2 ** attempt * 3
                            print(f"速率限制，等待 {wait_time}秒后重试...")
                            await asyncio.sleep(wait_time)
                            continue
                        raise Exception(f"TTS API错误: {response.status_code} - {response.text}")
                    
                    result = response.json()
                    
                    # 验证返回格式
                    if 'choices' not in result or len(result['choices']) == 0:
                        raise Exception(f"TTS返回格式错误: {result}")
                    
                    choice = result['choices'][0]
                    if 'message' not in choice:
                        raise Exception(f"TTS返回缺少message字段: {choice}")
                    
                    message = choice['message']
                    if 'audio' not in message:
                        raise Exception(f"TTS返回缺少audio字段: {message}")
                    
                    audio = message['audio']
                    if 'data' not in audio:
                        raise Exception(f"TTS返回缺少audio.data字段: {audio}")
                    
                    return base64.b64decode(audio['data'])
                    
                except httpx.TimeoutException:
                    if attempt == 2:
                        raise Exception("TTS API调用超时，已重试3次")
                    print(f"超时，正在重试 ({attempt + 1}/3)...")
                    await asyncio.sleep(2)
            
            raise Exception("语音合成失败")
```
