# Phase 56 E 配额 证据与验收

## 先核实实时额度

用户已说明配额重置。执行侧启动时查询实际账号余额、reset 时区、视频提交秒数计量、图片/文本额度、请求频率及在途限制，保存时点快照。历史 500 秒只作排期参考，不当作当前实测余额。

用“提交请求的源时长及实际计费”计视频消耗，不能拿成功落盘的视频长度冒充。记录失败/重试是否计费；图片、文本、视觉检查和轮询的限制也纳入计划。

## 初始视频预算

以下均按每条源视频 8 秒，未含返工：

| 用途 | 运行/任务 | 初始秒数 |
| --- | --- | --- |
| P1 并发两轮 | 六个运行，每次五镜，共三十条 | 240 |
| P2 协作配对 | 两个运行，每次六镜，共十二条 | 96 |
| P3 恢复演练 | 一个运行，五条 | 40 |
| 核心合计 | 四十七条 | 376 |
| 其它预设冒烟 | 条件成立时，三个预设各一条 | 24 |
| 含最小冒烟合计 | 五十条 | 400 |

若实际余额为 500 秒，上述参考计划可留 100 秒给返工与事故。这个预留不是保证所有修复都够，也不覆盖图片/文本。冒烟模板不支持一镜、真实拍摄单增镜或某组需补复验时，先重算；不能硬压模板来凑数。

提交前原子预留额度和在途容量；未知提交、未确认取消不随意释放为“可重新使用”。失败消耗照实计入。额度即将不够时保存运行和已获成果，按实际刷新机制续做，不索要每一批的重复启动许可，也不擅自新增收费来源。

核心样本优先于扩成长片；剩余额度不足时把额外冒烟/复验排到下一周期，清楚写未完成。不要用跳审、短源片或删关键动作维持“当日全部完成”。

## 证据最小集

每个 run 关联：项目/克隆、故事与输入哈希、模式及全部策略版本、实际模型/参数、实际容量与覆盖来源、会话/grant/接力记录、开始/终态、输出与介入。

每项媒体记录：逻辑请求/attempt、依赖及 ready 时刻、派发/提交/Provider ID、完成观察区间、收货版本、输入 manifest、计费及候选选择。重复观察不增加任务数。

交付至少包括 `runs.csv`、`media_tasks.csv`、规范化事件、`interventions.csv`、审核/修复及选版清单、usage/额度变化、原日志引用和可播放候选。不存在的事件填 unknown，不倒填当时的事前决策。

## 统计方法

- 原始墙钟、素材冷启动、输入就绪后制作、人工劳动、等待用户、模型/Provider 等待分别列；并发区间用并集或依赖时间线，不直接相加。
- 首轮收货与机器检查后终态分列，避免把返工差异全归因于队列。
- 主动故障注入单列，不混入正常速度。服务端异常、休眠、重启和救援保留在全程数据中，可另做有标记的分段分析。
- 所有启动的运行都留在完成/失败分母。速度子集只比较双方均完成且负荷一致的案例，并披露排除项。
- 比例按 `(串行历时-候选历时)/串行历时` 计算，基线为零/缺测时不算。逐运行列原值，再列配对差值/比例，使用 Python 计算并反算。
- 不把同片镜头当独立影片样本，不用两轮或单个配对宣称统计显著。没有活动记录就不虚构人工劳动分钟数。
- 不用不同题材项目的绝对耗时直接判模式快慢；跨题材主要检查瓶颈与边界是否重现。

## 独立报告

1. `PHASE56_A_MECHANISM_REPORT.md`：改动、默认与实际生效配置、定向/回归。
2. `PHASE56_B_CONCURRENCY_REPORT.md`：逐档真实时序、正常运行效率、失败和建议档位。
3. `PHASE56_C_PROJECT_COLLAB_REPORT.md`：P2 配对、其它模式冒烟、剧情负荷与跨题材边界。
4. `PHASE56_D_AUTONOMY_RECOVERY_REPORT.md`：接力、恢复、自动修复与人工救援。
5. `PHASE56_FINAL_REPORT.md`：哪些已经实现、真机验证、观察到改善，哪些仍待验证；推荐实验配置与回退方法。

报告可简洁，但原始账本和证据索引必须可复算。正文分别写“机制”“效率”“自主性”“候选画面”“用户接受”，不合并为单一 PASS。

## 阶段验收与收尾

本轮主要目标是更短等待、更少手工推动。机制正确但受 Provider 排队没有提速，可以写有效发现；更快但漏传输入、重复提交或人工补完，不能作为成功。

机器基本检查之后集中交看片材料，说明问题时间点，用户不需要逐镜推动。旧素材和失败候选都保留。实验默认按用户选择留为可选/默认的实验版本；六员与旧配置仍可显式回退，在途快照不受影响。

若只完成部分批次，报告具体状态和后续可恢复入口。完成可独立推进的工作，不停在“可以继续”；真正需要用户偏好或超范围授权时，先提供具体可审结果再提出。
